Struktur Folder dan Hak Akses (Folder Structure & Access Rights)

☁️📁🔐

Selamat Datang, Detektif Awan! (Welcome, Cloud Detective!)

Kamu akan menyelesaikan 4 misi untuk menata ruang kerja awan (cloud workspace) dan mengatur hak akses (access rights) dengan aman.

🏷️ Misi 1 Perbaiki Nama Berkas (Fix File Names)
🌳 Misi 2 Susun Struktur Folder (Build Folder Structure)
🔑 Misi 3 Matriks Hak Akses (Access Matrix)
🕵️ Misi 4 Detektif Akses (Access Detective)

💡 Prinsip Emas (Golden Rule): Beri Seperlunya (Least Privilege) — berikan hak akses paling kecil yang masih cukup untuk menyelesaikan tugas.

📌 Cara Main (How to Play): Kerjakan level secara berurutan. Setiap jawaban benar bernilai 10 poin. Progresmu otomatis tersimpan di perangkat ini.

Misi 1 / Level 1

🏷️ Perbaikan Nama Berkas (Fix File Names)

Instruksi (Instruction): Ubah nama berkas berantakan menjadi nama yang baik dengan pola TAHUN-BULAN-TANGGAL_Topik_Pembuat_vNomor.

Contoh: 2026-10-05_Proposal-Pensi_Rani_v2.docx

Misi 2 / Level 2

🌳 Susun Struktur Folder (Build Folder Structure)

Instruksi (Instruction): Tarik (drag) kartu ke tempat yang tepat. Folder proyek masuk ke folder induk, sub-folder masuk ke dalam folder Dokumentasi, dan berkas yang bukan bagian proyek dibuang ke kotak merah.

📁 PENTAS_SENI_KELAS9_2026
⬇ Letakkan folder utama di sini (Drop main folders here)
📁 04_Dokumentasi
⬇ Letakkan isi Dokumentasi di sini (Drop documentation sub-folders here)
❌ Bukan bagian proyek ini (Not part of this project)

🎴 Kartu Tersedia (Available Cards)

Misi 3 / Level 3

🔑 Matriks Hak Akses (Access Matrix)

Instruksi (Instruction): Pilih peran yang tepat untuk setiap orang pada setiap folder. Ingat prinsip Beri Seperlunya (Least Privilege). Satu baris dinilai benar jika seluruh kolomnya tepat.

Orang / Kelompok
(Person / Group)		 01_Proposal 02_Anggaran 03_Rundown 04_Dokumentasi
Keterangan Peran (Role Legend):
  • Pemilik (Owner) — Semua hak, termasuk menghapus permanen.
  • Penyunting (Editor) — Boleh mengubah, menambah, menghapus isi.
  • Pemberi Komentar (Commenter) — Boleh memberi saran, tidak boleh mengubah isi.
  • Pelihat (Viewer) — Hanya boleh membaca.
  • — — Tanpa akses.
Misi 4 / Level 4

🕵️ Detektif Akses (Access Detective)

Instruksi (Instruction): Kelompok Garuda mengelola Bazar UMKM Kelas 9. Periksa setiap folder di Drive mereka. Temukan masalahnya dan pilih perbaikan yang tepat.
