# ☁️ LKPD Interaktif — Cloud Collaboration: Struktur Folder dan Hak Akses

Aplikasi web edukatif berbasis **HTML5 + CSS3 + Vanilla JavaScript** yang berfungsi sebagai
**Lembar Kerja Peserta Didik (LKPD) Digital** untuk mata pelajaran **Informatika Kelas 9 SMP**,
materi **Cloud Collaboration: Struktur Folder dan Hak Akses**.

> **SMP Negeri 19 Kota Bekasi · Tim MGMP Informatika · © 2026**

---

## 🎯 Tujuan Pembelajaran

Melalui 4 misi interaktif, murid dapat:
1. Menjelaskan penyimpanan awan (*cloud storage*) dan manfaat kolaborasi berbasis awan.
2. Merancang struktur folder yang logis dan menamai berkas secara konsisten.
3. Menerapkan hak akses (*permission*) sesuai kebutuhan setiap anggota.
4. Menganalisis risiko berbagi tautan dan memperbaiki pengaturan yang tidak aman.
5. Merefleksikan kebiasaan digital dan berkomitmen menjaga data bersama.

---

## 🎮 Struktur Gameplay (4 Misi)

| Misi | Judul | Mekanisme | Poin Maks |
|------|-------|-----------|-----------|
| 1 | **Perbaikan Nama Berkas** (*Fix File Names*) | Isi nama berkas dengan pola `TAHUN-BULAN-TANGGAL_Topik_Pembuat_vNomor` | 50 |
| 2 | **Struktur Folder** (*Folder Structure*) | Drag-and-drop kartu folder ke zona yang tepat | 100 |
| 3 | **Matriks Hak Akses** (*Access Matrix*) | Pilih peran tiap orang pada tiap folder | 60 |
| 4 | **Detektif Akses** (*Access Detective*) | Temukan masalah & perbaikan pada 4 studi kasus | 80 |
| | | **TOTAL** | **290** |

---

## 🗣️ Sistem Dwibahasa

Seluruh antarmuka dan istilah menggunakan kombinasi **Bahasa Indonesia + Bahasa Inggris**.
Contoh: `Pelihat (Viewer)`, `Penyunting (Editor)`, `Pemilik (Owner)`, `Tautan (Link)`.
